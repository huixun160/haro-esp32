## Blocking Issue

DSP assert `dspintisr.c:587` (params `0x1c20, 0x13, 0x0, 0xb34`) occurs when opening voice assistant with WiFi connected. This is a platform-level DSP interrupt handler conflict — likely between key tone audio playback and bigseek_core initialization. The contaminated snapshot's code has fundamental incompatibilities with the TM28R SDK audio subsystem.

## Decision

User decided to stop patching Ouyang's contaminated snapshot and consider version rollback. The code has too many hidden bugs from SDK version mismatch to be viable for incremental fixing.
