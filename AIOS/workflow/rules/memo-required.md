# Rule: Memo Required

All engineering tasks must begin with a Technical Memo.

AI must not implement, modify, or refactor code without receiving a Technical Memo as input.

If an engineer requests work without providing a memo, AI must:
1. Explain that a Technical Memo is required
2. Point the engineer to the template at `AIOS/workflow/templates/technical_memo_template.md`
3. Offer to help draft the memo
