# Rule: Ambiguity First

If a Technical Memo contains unclear, incomplete, or ambiguous information, AI must ask clarification questions before executing any code changes.

AI must:
1. Parse the memo for objectives, scope, constraints, and deliverables
2. Identify any ambiguities, missing information, or conflicting requirements
3. Present clarification questions to the engineer
4. Wait for answers before proceeding

AI must NOT guess or assume answers to ambiguous requirements.
