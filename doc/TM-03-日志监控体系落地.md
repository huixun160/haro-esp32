# TM-03 日志监控体系落地

优先级: P1

## 目标

建立可追溯日志链路，保证“云端返回了什么 JSON、设备执行了什么动作、最终结果如何”都可查询。

## 范围

- websocket 原始事件镜像
- 对话生命周期日志
- 舵机动作日志
- 会话导出能力（串口或本地接口）

## 日志分层

1. 会话层
- `boot_session_id`
- `dialog_turn_id`
- 用户文本/模型文本摘要

2. 协议层
- 原始 `event_type` + `data`（脱敏后）
- 上下行音频事件里程碑

3. 动作层
- 动作 JSON
- 执行开始/结束/结果
- 执行耗时

## 数据策略

- 本地 ring buffer（建议最近 500 条）
- 导出格式 JSON Lines
- 可配置日志级别（INFO/DEBUG/TRACE）

## 建议修改文件

- `main/application.cc`
- `main/protocols/websocket_protocol.cc`
- 新增 `main/telemetry/logger.*`（建议）

## 验收标准

- 可导出任意一轮完整事件链。
- 能回答三个问题:
- 云端回了什么
- 设备做了什么
- 为什么成功或失败

## 交付物

- 日志字段字典
- 示例导出文件
- 最小排障手册（5 个常见问题）
