# TM-02 语义控制舵机能力落地（替代固定动作模组）

优先级: P1

## 目标

把“预设动作模组触发”升级为“云端语义理解 -> 结构化动作 JSON -> 设备执行”，当前阶段只支持 2 个舵机。

## 产品约束

- 仅使用 2 个舵机:
- 舵机 A: 头部（抬头/低头，上下方向控制）
- 舵机 B: 底座（左转/右转，左右方向控制）

## 范围

- 定义动作 JSON 协议（强约束 schema）。
- 建立语义到动作的映射执行链路。
- 动作队列、互斥与限位保护。
- 回执事件（accepted/started/completed/failed）。

## 非目标

- 六舵机全身动作编排。
- 复杂轨迹规划。

## 动作协议（建议）

```json
{
  "action_id": "uuid",
  "target": "head_servo|base_servo",
  "direction": "up|down|left|right",
  "angle_deg": 15,
  "speed": 0.6,
  "duration_ms": 600,
  "priority": "normal"
}
```

设备端强约束：

- 角度限制（软限位）
- 速度限制
- 同目标串行执行
- 超时自动失败回执

## 建议修改文件

- `main/mcp_server.cc` 或动作调度模块
- `main/application.cc`
- `main/boards/otto-robot/*`（舵机驱动入口）
- 新增 `main/robot_actions/*`（建议）

## 验收标准

- 语义命令“抬头/低头/左转/右转”稳定触发对应舵机。
- 连续 100 次动作执行无越界、无死锁。
- 每个动作均有标准回执（成功或失败）。

## 交付物

- 动作协议文档
- 设备执行状态机图
- 10 条典型语义到动作的对照测试记录
